## 输入

Draft：version（修改必填）、kind APPLICATION 或 CLAIM、title、category、budgetMonth yyyy-MM、amount（申请金额元）、purpose、managerId、financeId、applicationId（可空）、lines。

LineInput：expenseDate yyyy-MM-dd、description、amount（元）、issuer、reference。CLAIM 服务端按明细重算总额，客户端总额不可信。

Command：version、requestKey（8–80 位字母数字横线下划线）、note。finance-approve 可带 allowOverBudget=true；pay 带 amount / reference / method / paymentDate；reverse 带 paymentId。命令：submit、recall、manager-approve、finance-approve、reject、cancel、close、pay、reverse。除 submit 外必须填写 note。完全相同 requestKey 和内容可重试，更改内容拒绝；成功重试返回当前详情，不重复记账。

BudgetInput：version（修改）、departmentId、category、budgetMonth、limit（元）。键不可修改。

管理 type 限于 users / roles / departments / permissions / menus / dictionaries / settings，字段见页面及 AdminService.Input；权限、菜单、参数不能新增／删除。users 输入 password 而非 passwordHash，散列永不返回。角色 scope ALL / DEPARTMENT / ASSIGNED，permissions 必须已登记。

## 输出和限额

金额字段 amountCents / paidCents / reservedCents / limitCents / committedCents 为整数分。费用列表返回 items / total，page 从零开始，size 1–100，sort newest（编号降序）、amount、title。详情 actions 是当前账号可尝试命令，业务提交仍重新检查关联、预算和状态。

汇总与待办最多 10,000 条，超出 REPORT_LIMIT；目录上限 10,000。上传 single ≤5 MiB，总请求 ≤6 MiB、每单 ≤20。单笔和单据合计 ≤100,000,000 元。错误 INVALID_AMOUNT、BUDGET_REQUIRED、EVIDENCE_REQUIRED、DUPLICATE_RECEIPT、OVERPAYMENT、STALE_VERSION 等均须按实际提示修正，不能绕过校验重试。

JSON 导出保留费用内容、付款和流转元数据，不添加品牌广告，不包含凭证字节。下载不执行银行支付或税务认证。
